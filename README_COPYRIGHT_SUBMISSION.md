## ⚖️ Critical Legal & Statutory Principles under Indian Law

### 1. Authorship of AI-Assisted Software
- **Section 2(d)(i) of the Copyright Act, 1957:** Defines the author of a literary work as the person who created the work. Under longstanding precedent and official circulars of the Indian Copyright Office, **an author MUST be a natural human person**.
- **Google Antigravity:** The project was developed using Google Antigravity, an advanced AI-assisted coding environment. **Do NOT name "Google Antigravity" or "AI" as an author.** Doing so will trigger an immediate discrepancy notice and potential rejection by the Registrar.
- **Legal Characterization:** The human software engineer(s) who directed, prompted, architected, curated, refined, debugged, and integrated the code are the sole **legal human authors**. Google Antigravity is legally categorized as a *computer-aided tool / electronic instrument*, equivalent to an intelligent compiler or IDE.
- **Disclosure:** This relationship is fully and transparently disclosed in `01_Project_Description.pdf` and `05_Development_Ownership_Declaration.pdf` to ensure compliance with the duty of utmost good faith.

### 2. Ownership: Individual vs. Corporate / Employer
- **Section 17(c) (Work Made for Hire):** If the human author developed the software during the course of regular employment under a contract of service with the applicant firm/company, the employer is the **first owner** of the copyright.
- **Section 19 (Assignment Deed):** If the developer was an independent contractor or founder prior to incorporation, a formal **Copyright Assignment Deed** must be executed transferring all proprietary rights in the software to the applicant company.
- **No Objection Certificate (NOC):** When the applicant is a company/firm and not the individual human author, the application **must** be accompanied by a signed NOC from the human author(s).

### 3. Source Code & Object Code Deposit (Rule 70(5))
- Under the Copyright Rules, 2013 and official filing instructions, computer software applications require the deposit of **source code** and **object code**.
- **Voluminous Rule:** When code exceeds 20 pages (this frontend project comprises 118 files and over 23,500 lines of code), the Copyright Office requires the deposit of **the first 10 pages and the last 10 pages** of the source code and object code, without redacting or blocking.
- `02_Frontend_Source_Code.pdf` and `03_Object_Code.pdf` have been constructed to satisfy this requirement.

## 📝 Step-by-Step Filing Procedure on `copyright.gov.in`

### Step 1: Account Creation & Portal Login
1. Navigate to the official portal: **[https://copyright.gov.in](https://copyright.gov.in)**.
2. If filing for the first time, click **"New User Registration"**. Fill in the applicant/representative details and complete email/mobile OTP verification.
3. Log in to your e-Filing dashboard.

### Step 2: Form XIV Online Application
1. From the e-Filing menu, click **"Apply for Registration of Copyright (Form-XIV)"**.
2. Select the Work Category: **"Literary/ Dramatic"** -> Subcategory: **"Computer Software"**.

### Step 3: Statement of Particulars (SoP) — Column-by-Column Guide

| Col # | Field on Portal | Recommended Entry / Guidance |
| :---: | :--- | :--- |
| **1** | Registration Number | *Leave blank (system-generated upon issuance).* |
| **2** | Name, Address & Nationality of Applicant | Enter full legal name of Applicant (Company / LLP / Individual), registered address, PIN, email, and mobile phone. State Nationality as "Indian". |
| **3** | Nature of the Applicant’s Interest | Select **"Owner"** (if company under Section 17(c) or 19) or **"Author"** (if individual developer applying directly). |
| **4** | Class and Description of the Work | Class: **Literary (Computer Software)**.<br>Description: *Interactive frontend Single Page Application (SPA) providing real-time telephonic voice agent management, PSTN call monitoring, multi-lingual conversational AI orchestration, lead intelligence qualification, dynamic questionnaire editing, and multi-tenant business administration.* |
| **5** | Title of the Work | **ARB SoftTech AI Enterprise Voice Calling Agent Platform — Frontend Software** |
| **6** | Language of the Work | **TypeScript, JavaScript (ES2022), HTML5, CSS3** |
| **7** | Name, Address & Nationality of Author | Enter the **full legal name(s)** of the human software engineer(s), residential address, and nationality. State "No" to whether the author is deceased. *(Do not name AI tools).* |
| **8** | Whether the Work is Published or Unpublished? | **Unpublished** (if proprietary internal enterprise software not sold off-the-shelf to the general public) OR **Published** (if made publicly accessible online).<br>*Recommendation:* If deployed as an internal enterprise SaaS platform, select **"Unpublished"**, state Year of Completion as **2026**, and Location as India. |
| **9** | Year and Country of First Publication | *(Applicable only if Published)*: Enter Month/Year (e.g. October 2026) and Country: **India**. |
| **10** | Name, Address & Nationality of Owners | Enter Applicant Company/Entity details as current copyright owner. |
| **11** | Persons authorized to assign or license | Enter Applicant Company/Entity name and authorized signatories. |
| **12** | Location & custodian of original work | State: *Stored in secure electronic version control repositories at registered office of Applicant.* |
| **13** | Remarks / AI Disclosure | *Software created by human author(s) utilizing Google Antigravity as an assistive coding tool. Third-party open source libraries (React, Vite, Tailwind, etc.) are disclaimed under Section 52.* |

### Step 4: Statement of Further Particulars (SoFP)
1. **Col 1 (Originality):** State *"Yes, the computer software is an original literary work created by the author(s)."*
2. **Col 2 (Adaptation):** State *"No, it is not an adaptation of an existing work."*
3. **Col 3 (Third-Party Elements):** State *"The software utilizes permissive open-source development dependencies (MIT/Apache 2.0) which are disclaimed. Copyright is claimed exclusively over the original frontend source code and UI architecture authored for this platform."*
4. **Col 4 (Trademark Connection):** State *"No, the software title does not conflict with any registered trademark."* (Or provide TM details if ARB SoftTech is a registered mark).

### Step 5: Uploading Accompanying Documents
Upload the generated PDF documents in the portal's upload section:
1. **01_Project_Description.pdf** -> Upload as Project Description / Abstract.
2. **02_Frontend_Source_Code.pdf** -> Upload as Source Code evidence (First 10 & Last 10 Pages).
3. **03_Object_Code.pdf** -> Upload as Object Code evidence (First 10 & Last 10 Pages).
4. **04_Technical_Documentation.pdf** -> Upload as Technical Documentation.
5. **05_Development_Ownership_Declaration.pdf** -> Duly completed and signed, along with Author NOC.

### Step 6: Statutory Fee Payment
- Pay via the integrated Bharatkosh gateway:
  - **₹500** for Individual / Non-commercial applicant
  - **₹2,000** for Commercial entity / Private Limited Company / LLP.
- Download and save the official Payment Challan / Receipt.

### Step 7: Generation of Diary Number & Post-Filing Timeline
1. Upon payment, the portal immediately issues a **Diary Number** (e.g. `12345/2026-CO/L`).
2. Download the official **Acknowledgement Slip (Form XIV)**.
3. **Mandatory 30-Day Waiting Period:** Under Section 45 and Rule 70(9), the application enters a mandatory 30-day statutory objection period during which any person may inspect or raise objections.
4. **Scrutiny by Examiner:** Following 30 days, an Examiner of Copyrights reviews the application:
   - If no discrepancies are found, the work is approved and a **Registration Certificate (ROC)** is issued.
   - If the Examiner issues a Discrepancy Letter (often requesting clarification on author employment or source code deposit), submit a formal written response referencing this documentation package within 30 days.
